Substack-AI+

AI writing assistant for Substack newsletters

Get it on Chrome Web Store

Features

📝 Title suggestions

AI generates multiple title candidates from your draft, optimized for newsletter open rates.

📊 Paragraph rhythm

Analyzes English cadence and suggests rhythm adjustments for natural reading flow.

📧 Subject A/B testing

5 subject line variations to maximize open rate.

🪝 Lead paragraph optimizer

Keep readers past the paywall with optimized opening 3 paragraphs.

🤖 Multi-AI support

Choose between Claude / GPT / Gemini. Your API keys stay in your browser.

🔒 Privacy first

Article content is sent only to your chosen AI provider. No Substack-AI+ servers involved.

Pricing

Free: Basic AI suggestions (30 generations/month).
Pro ($9/month): Unlimited generation + prompt template library + history management + multi-AI parallel + Substack-specific features. Coming soon.

How to use

  1. Install from the Chrome Web Store
  2. Open your Substack post composer
  3. Click the 🤖 icon in the toolbar
  4. Set up your AI provider (Claude / GPT / Gemini) and API key
  5. Draft → AI assistance → Publish
