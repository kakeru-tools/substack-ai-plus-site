FAQ

Is it really free?
Yes. Core features are free. AI usage costs are billed by your own API provider (Claude Haiku is roughly $0.01–0.10 per article).
What's an API key?
A credential issued by Anthropic (Claude) or OpenAI when you create an account. Settings inside the extension guide you through obtaining one.
Is this an official Substack feature?
No. This is a third-party Chrome extension built by an independent developer. Not affiliated with Substack Inc.
Where is my data stored?
API keys and settings are saved only in your Chrome's local storage. Nothing is sent to our servers.
Does it work with paid Substack publications?
Yes. The extension runs locally in your browser, so it works regardless of your Substack tier.
